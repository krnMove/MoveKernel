## MoveKernel 1.6.1: задачи, прокрутка консоли и файловая система

При загрузке отображается крупный текстовый логотип `MOVE`, затем — приглашение командной строки.

Файлы хранятся на отдельном диске `os/data.img`, подключённом как primary IDE slave.
Образ создаётся при сборке, если его ещё нет; повторная сборка сохраняет существующие данные.
Запускайте систему через `run_os.ps1`, чтобы QEMU подключил оба диска.

Команды консоли:

- `/pwd` — показать текущий каталог;
- `/cd <каталог>` — перейти в каталог; `/cd /` возвращает в корень;
- `/mkdir <каталог>` — создать каталог внутри текущего или указанного родительского каталога;
- `/ls` — показать содержимое текущего каталога;
- `/touch <имя>` — создать пустой файл, например `/touch note.txt`;
- `/write <имя> <текст>` — записать или заменить содержимое;
- `/cat <имя>` — прочитать файл;
- `/rm <имя>` — удалить файл;
- `/spawn` — запустить задачу-счётчик;
- `/tasks` — показать задачи и их счётчики.

Файлы и каталоги поддерживают относительные пути от текущего каталога и абсолютные
пути от корня. Например: `/mkdir docs`, `/cd docs`, `/touch note.txt`, `/cd ..`.
Каталоги и файлы сохраняются на `os/data.img`; текущий каталог после перезапуска
сбрасывается в корень. При монтировании автоматически создаются каталоги
`/kernel`, `/move`, `/user`, `/bin`, `/uland`, `/system`, `/apps` и `/private`.
Приглашение командной строки показывает текущий каталог, например `MoveKernel/kernel>`.

Shift+Enter начинает следующую строку команды, а обычный Enter выполняет все введённые
строки по очереди.

Файлы в `/ls` выводятся по одному на строку. Когда текст доходит до нижнего края экрана,
консоль прокручивается вниз; `/clear` очищает экран и начинает вывод сверху.

Планировщик использует PIT с частотой 100 Гц и переключает до трёх задач-счётчиков по
таймеру. Это демонстрационная многозадачность внутри ring 0 на одном процессоре; отдельные
адресные пространства, пользовательский режим и TSS пока не реализованы.

Чтобы проверить переключение задач, запустите `.\build_os.ps1`, затем `.\run_os.ps1`.
В консоли QEMU выполните `/spawn`, а затем `/tasks`; повторите `/tasks` через некоторое
время и сравните значение `COUNTER` у задачи `counter` — оно должно увеличиваться.
Можно выполнить `/spawn` ещё раз, чтобы запустить дополнительные счётчики.

Это собственная простая файловая система, не FAT: максимум 32 файла и каталога вместе,
24 байта на полный путь, 1024 байта на файл и 16 KiB суммарного содержимого.
Файлы сохраняются между перезапусками
QEMU, пока сохраняется `os/data.img`. Не удаляйте и не обнуляйте этот образ, если хотите
сохранить данные.
