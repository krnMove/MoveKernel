## MoveKernel 1.5.0: файловая система

Файлы хранятся на отдельном диске `os/data.img`, подключённом как primary IDE slave.
Образ создаётся при сборке, если его ещё нет; повторная сборка сохраняет существующие данные.
Запускайте систему через `run_os.ps1`, чтобы QEMU подключил оба диска.

Команды консоли:

- `/touch <имя>` — создать пустой файл;
- `/write <имя> <текст>` — записать или заменить содержимое;
- `/cat <имя>` — прочитать файл;
- `/rm <имя>` — удалить файл;
- `/ls` — показать файлы.

Это собственная простая файловая система, не FAT: максимум 32 файла, 24 байта на имя,
1024 байта на файл и 16 KiB суммарного содержимого. Файлы сохраняются между перезапусками
QEMU, пока сохраняется `os/data.img`. Не удаляйте и не обнуляйте этот образ, если хотите
сохранить данные.
